# 教师简明操作说明

1. 用新版 Edge / Chrome 打开应用。默认“模拟演示”只显示固定示例；正式试用须由项目负责人配置服务，再选择“真实同传”并填写课堂口令。
2. 点击“检查麦克风”，允许权限，对麦克风说几句话，等待约 8 秒。电平应有变化。没有声音时检查 Windows 输入设备和音量。
3. 点击“英文试听”，确认学生耳机线路能听到英文。试听使用浏览器英语语音；若没有安装可用英语语音，请由项目负责人处理。它不代表讯飞服务验证成功。
4. 点击“打开字幕窗口”，允许弹窗。拖到字幕投影仪，调整字号并点击“全屏”；另一块投影画面显示双语 PPT。
   若需比较英文声音延迟，可在开始前将“英文声音来源”改为“本机朗读英文字幕（对比测试）”。此方式只读确认后的英文字幕，需要本机英语语音；仍消耗讯飞同传额度，延迟改善需实测。课堂中不能切换，需先暂停或结束。
   若字幕本身也等待较久，可将“分句方式”设为“停顿后尽快送译（实验）”，先用短句检查速度，再检查长句与正常停顿是否漏字。实验模式约 0.8 秒停顿就分段；尚未完成长课和现场验证。
5. 点击“开始课堂”。真实模式下等待“课堂进行中”，先说一句完整中文，确认中英文字幕与英文声音都正常。
6. 临时离开或播放 PPT 视频前点击“暂停课堂”。暂停会立即停止采音与播放、清空队列。点击“继续课堂”会新建会话，暂停内容不会补译。
7. 若英文落后，查看待播秒数，必要时点击“清空待播，回到当前”。这会跳过旧语音并交接到新会话，可能有短暂缺失；请重述关键句。
8. 下课点击“结束课堂”。字幕暂留，麦克风和播放停止。刷新或关闭页面会清除历史。

授课时保持教师页面在前台，电脑不要休眠。浏览器音频被暂停时按提示恢复；若网络重连，请等待状态变化，关键句可重述。持续失败时用双语 PPT 继续授课，并联系负责人。不要把“正在重连”当作仍在翻译。

如需排查，展开“运行数据与排查”，下载运行数据。导出的文件不含课堂音频或字幕；不要把课堂口令或服务密钥发送到群聊。
