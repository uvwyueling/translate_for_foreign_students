# 家庭与学校验收清单

测试时间、操作者、应用地址、模式、浏览器版本、设备、网络、服务额度及函数限制须先记录。模拟测试与真实测试分别记录。

## 家庭环境

- [ ] 麦克风未授权、无设备、设备拔出时提示可理解，无虚假的运行状态。
- [ ] 英文试听能听到，音量变化生效；真实语音也进入同一路输出。
- [ ] 模拟结果显著标识，与真实讲话无关，不作为翻译质量与云端延迟证据。
- [ ] 独立字幕窗口能重开并取得最近字幕，字体、高对比、全屏正常；只播放一路语音。
- [ ] 同一句字幕修订不重复，真实中英文对应同一片段。
- [ ] 暂停后不上传、不播音；恢复建立新会话，不补译暂停内容。
- [ ] 结束后麦克风指示关闭，没有迟到语音；刷新清除历史。
- [ ] 清空待播后不补播旧句；长队列时长可见，到达上限明确停止采音。
- [ ] 主动断连、临时断网、长时断网分别测试，自动重试有上限，恢复后无重复语音，标明未覆盖区间。
- [ ] 至少一次真正的平台函数时限交接，记录恢复时长、重复、漏句与语音丢弃。
- [ ] 持续 45 分钟真实课程输入，开始、中段、末段检查采音与播放积压，记录页面资源和语义错误。
- [ ] 下载数字运行数据，确认没有音频、完整字幕或凭证；核对官方实际用量。

## 学校现场

- [ ] 无 VPN 能访问应用、静态资源、WebSocket；教师不登录 GitHub 或 Vercel 管理平台。
- [ ] 记录 Windows 与 Edge 具体版本，检查浏览器采音与英语语音包。
- [ ] 固定站位麦克风采音清楚，输入电平正常；教师页面前台运行且电脑不休眠。
- [ ] 记录音频分配设备型号和接线，25 个在用耳机逐一听到英文。
- [ ] 两个 VGA 投影画面独立，PPT 和字幕分别展示，后排字幕可读。
- [ ] 教师独立完成检查、试听、开始、暂停、继续、清空待播、结束。
- [ ] 现场断网或服务失败时能识别状态，并用双语 PPT 继续授课。
- [ ] 对课程翻译准确率、可接受延迟、缺句和持续积压作出单独评估。
