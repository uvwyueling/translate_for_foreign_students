## 本地运行

准备使用腾讯云国内节点做对照时，参照 [CloudBase Git 部署配置](docs/CLOUDBASE_DEPLOYMENT.md)。仓库已提供容器入口与 Dockerfile，控制台服务端口填写 `8080`；需要推送后由云端构建并实测到讯飞的连接，尚不能视为网络故障已解决。

要求 Node.js >= 22.12（本次使用 24.16）、npm，以及新版 Edge / Chrome。

```sh
npm ci
npm run dev
```

打开终端显示的前端地址（通常为 `http://127.0.0.1:5173`）。开发时后端监听 `127.0.0.1:3001`，前端自动转发 API 与 WebSocket。占用端口时先关闭其他实例，或者同时调整 `PORT` 与 `vite.config.ts` 中的代理端口。

```sh
npm run check       # 类型、生产构建、自动化测试
npm run build
npm start           # 在 3001 端口同时服务构建后的网页与后端
```

麦克风需要 HTTPS 或本机 localhost / 127.0.0.1。用普通 HTTP 局域网地址访问不能作为采音验证。

## 已实现

- 教师控制台：能力与麦克风检查、输入电平、后端 HTTP / WebSocket 检查、英文试听、课堂控制。
- AudioWorklet 连续采音、有状态重采样、16 kHz / 16 bit / 单声道小端 PCM、40 ms / 1280 字节分片。
- 独立字幕窗口：同源 BroadcastChannel、重开拉取最近状态、教师页面失联提示、全屏、字号、高对比度。
- 部分与最终字幕更新，同一片段修订不追加重复行；页面内最多 60 行，不保存课堂历史。
- 英文队列：排序、去重、音量、待播时长、清空后重建会话；60 秒硬上限，故障明确提示。
- 当前排查阶段，真实同传统一使用连续同传与讯飞英文语音，控制面板暂不提供实验分句和声源选项。已有对比实验记录见 [延迟测试](docs/LATENCY_TEST.md)。
- 暂停、结束：停止采音与播放，关闭上下游连接；会话标识过滤迟到事件。
- 开始 / 继续时，连接前已采到的语音在内存中暂存（上限 12 秒），连接后按 40 ms 节奏依次送出，避免立即讲话丢掉句首。等待“课堂进行中”后再讲可减少启动等待；暂存不覆盖麦克风尚未授权 / 开启的时间，暂停、失败及断线时清空，不补传断线期间内容。
- 心跳、超时、最多五次退避重连、主动时限交接、人工重试；中断不补传旧音频。
- 讯飞后端鉴权、上行请求、识别替换区间、翻译修订、PCM 合成语音适配。
- 仅数字运行数据导出：时长估算、近似字幕延迟、恢复时间、队列峰值；不含音频、字幕、口令。

## 配置真实服务

复制 `.env.example` 为本地 `.env`，填入 `XFYUN_APP_ID`、`XFYUN_API_KEY`、`XFYUN_API_SECRET`、`CLASSROOM_ACCESS_TOKEN`。真实模式要求四项齐备。修改后重启本地后端。

部署时在后端环境中配置相同变量，必要时设置 `ALLOWED_ORIGIN=https://实际域名`（不要末尾斜线）。页面只输入课堂口令，不输入讯飞密钥。凭证不要使用 `VITE_` 前缀，不要提交 `.env`。页面口令只保存在内存，经 WSS 首条消息提交，不放在 URL、投影消息或导出中。

后端健康检查只表示配置是否齐全，不表示账号有可用额度或已经连通讯飞。真实模式不会在失败时自动切换成模拟结果，也不会自动购买额度。

## 稳定性检查

```sh
npm run test:soak                    # 默认 45 分钟，模拟后端真实墙钟运行
SOAK_SECONDS=40 npm run test:soak     # 短测，覆盖 30 秒会话交接
```

此脚本仅检查模拟后端 WebSocket、示例输出与连接交接，输出数字汇总；不采集麦克风、不测试浏览器，也不能替代 45 分钟真实云端和学校验收。

## 实现说明

前端 `src/`，共用消息契约 `shared/`，后端 `server/`，Vercel 入口 `api/server.ts`。无课堂内容数据库。语音只在内存短时缓冲；不将课堂音频或字幕写入日志。

实现依据：[讯飞同传文档](https://www.xfyun.cn/doc/nlp/simultaneous-interpretation/API.html)、[Vercel WebSocket 文档](https://vercel.com/docs/functions/websockets)。实际供应商字段、时限与账号权限仍需通过真实联调验证。
